# Security policy

## Supported versions

Hush is in early development and does not store or manage secrets yet. Security updates are provided only for the latest published version.

## Reporting a vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Chitresh-code/hush/security/advisories/new). Do not include secrets, credentials, or sensitive production data in a report. Do not open a public issue for an unaddressed vulnerability.

Include the affected version, operating system, reproduction steps, impact, and any safe supporting evidence. The maintainers will acknowledge the report and coordinate remediation and disclosure through the private advisory.
